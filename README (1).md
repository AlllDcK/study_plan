# Учебный семестр: осень 2026

Приложение-трекер на один файл: `index.html`. Никаких зависимостей и сборки.

## Что внутри

- **Цели недели** — задачи по девяти направлениям на каждую из 13 недель, с галочками и полем заметок.
- **График недели** — два шаблона: недели 1–7 (набор материала) и 8–13 (производство).
- **Тесты** — 20 наборов, 159 вопросов, плюс автоматический набор «Работа над ошибками».
- **Книги** — полные выходные данные 21 источника.

## Публикация на GitHub Pages

1. Создать публичный репозиторий, залить `index.html` в корень.
2. Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)`, Save.
3. Через минуту-две страница доступна по адресу `https://<логин>.github.io/<репозиторий>/`.

Обновление: заменить `index.html`, закоммитить. Страница обновится сама.

## Где хранится прогресс

В `localStorage` браузера, на устройстве. На сервер ничего не уходит, в репозитории прогресса нет.
Телефон и ноутбук хранят его раздельно — для переноса внизу страницы есть кнопка
«Перенести на другое устройство»: копирует состояние одной строкой.

Режим инкогнито и встроенные браузеры мессенджеров хранилище не дают — в этом случае
вверху появится предупреждение.
