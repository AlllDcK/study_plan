Идея
Числовой ряд - это бесконечная сумма a1 + a2 + a3 + ... Если ряд сходится,
у него есть конечная сумма S. Ряды разных видов задаются разными формулами
и параметрами, но у любого сходящегося ряда есть первый член и сумма.
Первый член a1 является общим параметром, а сумма S - общим критерием,
по которому ряды сравниваются и сортируются.

Классы
Series - абстрактный класс, реализует Comparable<Series>.
  Общий параметр: a1 - первый член ряда.
  Абстрактные методы: term(n) - n-й член ряда, sum() - сумма ряда.
  Общие методы:
    partialSum(N) - частичная сумма первых N членов, одна реализация
                    для всех рядов, использует term(n);
    isAlternating() - является ли ряд знакочередующимся;
    compareTo() - сравнение по сумме через Double.compare.

GeometricSeries - геометрический ряд a1 + a1*q + a1*q^2 + ...
  Свой параметр: знаменатель q.
  Сходится при |q| < 1, сумма S = a1 / (1 - q).

ExponentialSeries - ряд Тейлора для экспоненты a1 * (1 + x + x^2/2! + ...).
  Свой параметр: аргумент x.
  Сходится при любом x, сумма S = a1 * e^x.

HarmonicSeries - обобщённый гармонический ряд a1 * (1 + 1/2^p + 1/3^p + ...).
  Свой параметр: показатель p.
  Сходится только при p > 1. Точной формулы суммы в общем случае нет,
  поэтому сумма считается приближённо: частичная сумма 100 000 членов
  плюс оценка остатка интегралом a1 * N^(1-p) / (p-1).
  Для проверки при p = 2 результат совпадает с pi^2/6.

Детали реализации
- Конструкторы наследников вызывают super(a1) и проверяют условие
  сходимости. Для расходящегося ряда (|q| >= 1 или p <= 1) бросается
  IllegalArgumentException, так как сумма у такого ряда не существует.
- equals() в базовом классе проверяет совпадение класса (getClass())
  и первого члена a1, наследники дополнительно сравнивают свой параметр.
  hashCode() переопределён согласованно с equals().
- toString() в каждом наследнике выводит вид ряда, его параметры,
  частичную сумму S_5 и сумму S. По S_5 видно, как частичные суммы
  приближаются к сумме ряда.
- Разные ряды могут иметь одинаковую сумму. Например, у геометрических рядов
  с a1 = 1, q = 0.5 и с a1 = 3, q = -0.5 сумма равна 2. Для них compareTo
  возвращает 0, а equals возвращает false. В ArrayList это не мешает
  сортировке, но TreeSet оставил бы только один из них.

Демонстрация
В список добавляются 9 рядов трёх разных видов вперемешку. Программа:
1) выводит исходный список;
2) сортирует ряды по возрастанию суммы (Collections.sort);
3) сортирует по убыванию суммы (Collections.reverseOrder);
4) находит ряды с наибольшей и наименьшей суммой (Collections.max / min);
5) делает выборку рядов с суммой от 1 до 3;
6) классифицирует ряды на знакочередующиеся и знакопостоянные;
7) проверяет, что сумма 1 + 1/4 + 1/9 + ... равна pi^2/6;
8) проверяет equals();
9) показывает, что расходящийся ряд создать нельзя.
